CSS Fundamentals

1. What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to style and design HTML elements on a web page.

CSS controls the appearance, layout, colors, spacing, fonts, responsiveness, and overall visual presentation of a website.

Example:

p { color: blue; }
  • HTML → provides the structure
  • CSS → provides the style
  • JavaScript → provides behavior and interactivity

CSS is commonly used for:

  • Colors
  • Fonts
  • Spacing
  • Layouts
  • Borders
  • Animations
  • Responsive design
  • Positioning
  • Flexbox
  • Grid

2. Inline CSS

Inline CSS is written directly inside the style attribute of an HTML element.

Syntax:

<p style="color: red;">Hello World</p>

Example:

<h1 style="color: blue; font-size: 30px;">
  Hello World
</h1>

Advantages:

  • Quick to write
  • Useful for small changes
  • Useful for testing styles

Disadvantages:

  • Difficult to maintain
  • Creates repetitive code
  • Not suitable for large websites

3. Internal CSS

Internal CSS is written inside the <style> element in the <head> section of an HTML document.

Example:

<head>
  <style>
    p {
      color: blue;
    }
  </style>
</head>

Advantages:

  • Easy to manage for a single page
  • Keeps CSS separate from individual HTML elements
  • Useful for page-specific styles

Disadvantages:

  • Cannot be easily reused across multiple pages
  • Can make HTML documents large

4. External CSS

External CSS is written in a separate .css file and connected to the HTML document.

HTML:

<link rel="stylesheet" href="style.css">

CSS:

p {
  color: blue;
  font-size: 20px;
}

Advantages:

  • Reusable across multiple HTML pages
  • Easy to maintain
  • Keeps HTML clean
  • Best approach for most real-world projects

Example Structure:

project/
├── index.html
└── style.css

5. CSS Syntax

CSS follows a specific syntax consisting of a selector, property, and value.

Basic Syntax:

selector {
  property: value;
}

Example:

p {
  color: red;
  font-size: 20px;
}

Parts:

  • p → selector
  • color → property
  • red → value
  • : → separates property and value
  • ; → ends a declaration
  • { } → contains the CSS declarations

Multiple Properties:

h1 {
  color: blue;
  font-size: 32px;
  text-align: center;
}

6. CSS Comments

CSS comments are used to write notes inside CSS code.

CSS comments are ignored by the browser and are not displayed on the webpage.

Syntax:

/* This is a CSS comment */

Example:

/* Heading styles */
h1 {
  color: blue;
}

Multi-line Comment:

/*
  This is a
  multi-line CSS comment
*/

7. CSS Selectors

CSS selectors are used to select HTML elements that we want to style.

1. Element Selector

Selects all elements of a particular HTML tag.

p {
  color: blue;
}

This selects all <p> elements.

2. Class Selector

A class selector starts with ..

.box {
  background-color: yellow;
}

HTML:

<div class="box">Hello</div>

3. ID Selector

An ID selector starts with #.

#header {
  color: red;
}

HTML:

<h1 id="header">Welcome</h1>

4. Universal Selector

The universal selector * selects all elements.

* {
  margin: 0;
  padding: 0;
}

5. Group Selector

Multiple selectors can be grouped using a comma.

h1, h2, p {
  color: blue;
}

8. CSS Properties

CSS properties define what aspect of an HTML element we want to change.

Example:

p {
  color: red;
  font-size: 20px;
}
  • color → changes text color
  • font-size → changes text size

Common CSS Properties:

  • color
  • background-color
  • font-size
  • font-family
  • font-weight
  • text-align
  • width
  • height
  • margin
  • padding
  • border
  • display
  • position

9. CSS Values

CSS values specify the actual setting for a CSS property.

Example:

color: red;
  • color → property
  • red → value

Common Types of CSS Values:

1. Color Values

color: red;
color: #ff0000;
color: rgb(255, 0, 0);

2. Length Values

width: 200px;
width: 50%;
width: 10rem;
width: 5vw;

3. Number Values

opacity: 0.5;
line-height: 1.5;

4. Keyword Values

display: block;
position: relative;
text-align: center;

5. Function Values

width: calc(100% - 20px);
color: rgb(255, 0, 0);

Common Units:

  • px → pixels
  • % → percentage
  • em → relative to parent/current font size
  • rem → relative to root font size
  • vw → viewport width
  • vh → viewport height

The following example combines selector, property, and value.

.card {
  background-color: white;

  width: 300px;
  padding: 20px;

Breakdown:

  • .card → selector
  • background-color → property
  • white → value
  • color → property
  • black → value
  • width → property
  • 300px → value
  • padding → property
  • 20px → value

Notes

Note: CSS stands for Cascading Style Sheets.

Note: Inline CSS is written inside the style attribute.

Note: Internal CSS is written inside the <style> tag.

Note: External CSS is written in a separate .css file.

Note: A CSS rule consists of a selector and one or more declarations.

Note: A declaration consists of a property and a value.

Note: Selectors determine which HTML elements are styled.

Note: Properties define what you want to change, while values define how you want it changed.

CSS Selectors

1. Element Selector

The element selector selects all HTML elements with a specific tag name.

Syntax:

p {
  color: blue;
}

Example:

h1 {
  color: red;
}

p {
  font-size: 20px;
}

The above CSS applies to all <h1> and <p> elements.

HTML:

<h1>Hello</h1>
<h1>Welcome</h1>
<p>First paragraph</p>
<p>Second paragraph</p>

Use:

Use an element selector when you want to apply the same style to all elements of a particular type.

2. Class Selector

The class selector selects HTML elements that have a specific class attribute.

A class selector starts with a . (dot).

Syntax:

.box {
  color: red;
}

HTML:

<div class="box">Box 1</div>
<div class="box">Box 2</div>

Example:

.box {
  background-color: yellow;
  padding: 20px;
}

All elements having class="box" will receive the style.

Important:

  • A class can be used on multiple elements.
  • An element can have multiple classes.
  • Class selectors start with ..

3. ID Selector

The ID selector selects an HTML element using its id attribute.

An ID selector starts with #.

Syntax:

#header {
  color: red;
}

HTML:

<h1 id="header">My Website</h1>

Example:

#header {
  color: blue;
  text-align: center;
}

Important:

  • ID should identify a specific element.
  • ID selectors start with #.
  • ID has higher specificity than a class selector.

4. Universal Selector

The universal selector selects all HTML elements.

It is represented using *.

Syntax:

* {
  margin: 0;
  padding: 0;
}

Example:

* {
  box-sizing: border-box;
}

This rule applies to every element on the page.

Common Use:

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

5. Attribute Selector

The attribute selector selects HTML elements based on their attributes or attribute values.

1. Attribute Exists

Selects elements that contain a particular attribute.

input[type] {
  border: 2px solid blue;
}

2. Exact Attribute Value

input[type="text"] {
  background-color: yellow;
}

HTML:

<input type="text">
<input type="email">

Only the input with type="text" will receive the style.

Common Attribute Selectors:

  • [attr] → attribute exists
  • [attr="value"] → exact value
  • [attr^="value"] → starts with value
  • [attr$="value"] → ends with value
  • [attr*="value"] → contains value

Example:

a[href^="https"] {
  color: green;
}

6. Descendant Selector

The descendant selector selects elements that are inside another element at any nesting level.

It is represented using a space.

Syntax:

.container p {
  color: red;
}

HTML:

<div class="container">
  <p>Paragraph 1</p>
  <div>
    <p>Paragraph 2</p>
  </div>
</div>

Both paragraphs are descendants of .container, so both will be selected.

Important:

The descendant selector can select elements at any nesting level.

7. Child Selector

The child selector selects only the direct children of an element.

It is represented using the > symbol.

Syntax:

.container > p {
  color: red;
}

HTML:

<div class="container">
  <p>Direct Child</p>
  <div>
    <p>Nested Child</p>
  </div>
</div>

Only Direct Child will be selected.

Difference:

  • .container p → selects all descendant paragraphs
  • .container > p → selects only direct child paragraphs

8. Adjacent Sibling Selector

The adjacent sibling selector selects the element that comes immediately after another element.

It is represented using the + symbol.

Syntax:

h2 + p {
  color: red;
}

HTML:

<h2>Title</h2>
<p>This paragraph is selected.</p>
<p>This paragraph is not selected.</p>

Only the first paragraph immediately following the <h2> is selected.

Meaning:

A + B

Selects B only when B comes immediately after A.

9. General Sibling Selector

The general sibling selector selects all matching siblings that appear after a specific element.

It is represented using the ~ symbol.

Syntax:

h2 ~ p {
  color: blue;
}

HTML:

<h2>Title</h2>
<p>Paragraph 1</p>
<p>Paragraph 2</p>
<div>Other content</div>
<p>Paragraph 3</p>

All matching <p> siblings after the <h2> are selected.

Meaning:

A ~ B

Selects all matching B elements that are siblings appearing after A.

10. Grouping Selector

The grouping selector allows multiple selectors to share the same CSS rules.

Selectors are separated using a comma ,.

Syntax:

h1, h2, p {
  color: blue;
}

Example:

h1, h2, h3 {
  font-family: Arial;
  color: red;
}

The same styles will be applied to <h1>, <h2>, and <h3>.

Why use grouping?

  • Reduces duplicate CSS
  • Makes CSS shorter
  • Improves maintainability
  • Allows multiple elements to share styles

11. Selector Quick Reference

  • p → Element selector
  • .box → Class selector
  • #header → ID selector
  • * → Universal selector
  • [type="text"] → Attribute selector
  • .container p → Descendant selector
  • .container > p → Child selector
  • h2 + p → Adjacent sibling selector
  • h2 ~ p → General sibling selector
  • h1, h2, p → Grouping selector

Notes

Note: Selectors determine which HTML elements CSS will style.

Note: The . symbol is used for class selectors.

Note: The # symbol is used for ID selectors.

Note: The * symbol represents the universal selector.

Note: A space represents a descendant relationship.

Note: The > symbol selects only direct children.

Note: The + symbol selects the immediately following sibling.

Note: The ~ symbol selects matching following siblings.

Note: Commas are used to group multiple selectors.

CSS Colors & Backgrounds

1. Named Colors

CSS provides predefined color names that can be used directly as values.

Example:

color: red;
color: blue;
color: green;
background-color: yellow;

Common Named Colors:

  • red
  • blue
  • green
  • yellow
  • orange
  • purple
  • black
  • white
  • gray
  • pink

HTML + CSS:

<p style="color: red;">Red Text</p>

2. HEX Color

HEX stands for Hexadecimal. It represents colors using six hexadecimal characters.

A HEX color normally starts with #.

Syntax:

#RRGGBB
  • RR → Red
  • GG → Green
  • BB → Blue

Examples:

color: #ff0000; /* Red */
color: #00ff00; /* Green */
color: #0000ff; /* Blue */
color: #000000; /* Black */
color: #ffffff; /* White */

Short HEX:

#fff → White
#000 → Black
#f00 → Red

3. RGB Color

RGB stands for Red, Green, Blue.

Each value normally ranges from 0 to 255.

Syntax:

rgb(red, green, blue)

Examples:

color: rgb(255, 0, 0); /* Red */
color: rgb(0, 255, 0); /* Green */
color: rgb(0, 0, 255); /* Blue */
color: rgb(0, 0, 0); /* Black */
color: rgb(255, 255, 255); /* White */

Example:

background-color: rgb(30, 144, 255);

4. RGBA Color

RGBA is RGB with an additional Alpha channel.

The alpha value controls transparency.

Syntax:

rgba(red, green, blue, alpha)

Alpha Value:

  • 0 → completely transparent
  • 0.5 → 50% transparent
  • 1 → completely opaque

Example:

background-color: rgba(255, 0, 0, 0.5);

This creates red with 50% transparency.

5. HSL Color

HSL stands for Hue, Saturation, Lightness.

Syntax:

hsl(hue, saturation, lightness)

Components:

  • Hue → color angle from 0° to 360°
  • Saturation → intensity of the color
  • Lightness → brightness of the color

Examples:

color: hsl(0, 100%, 50%); /* Red */
color: hsl(120, 100%, 50%); /* Green */
color: hsl(240, 100%, 50%); /* Blue */

6. Background Color

The background-color property sets the background color of an element.

Syntax:

background-color: color;

Example:

body {
  background-color: lightblue;
}

Using HEX:

.box {
  background-color: #222;
}

7. Background Image

The background-image property adds an image to the background of an element.

Syntax:

background-image: url("image.jpg");

Example:

.hero {
  background-image: url("background.jpg");
}

Multiple Backgrounds:

background-image:
  url("image.png"),
  url("background.jpg");

Multiple background images can be placed using comma-separated values.

8. Background Size

The background-size property controls the size of a background image.

Common Values:

  • auto → default image size
  • cover → covers the entire element
  • contain → displays the complete image
  • 100% 100% → stretches image to element dimensions

Example:

.hero {
  background-image: url("hero.jpg");
  background-size: cover;
}

cover is commonly used for hero sections and landing pages.

9. Background Position

The background-position property controls where the background image is placed.

Common Values:

  • center
  • top
  • bottom
  • left
  • right
  • center center

Example:

.hero {
  background-image: url("hero.jpg");
  background-position: center;
}

Custom Position:

background-position: 50% 50%;

10. Background Repeat

The background-repeat property controls whether a background image repeats.

Common Values:

  • repeat → repeats horizontally and vertically
  • repeat-x → repeats horizontally
  • repeat-y → repeats vertically
  • no-repeat → does not repeat

Example:

.hero {
  background-image: url("pattern.png");
  background-repeat: no-repeat;
}

11. CSS Gradients

A gradient creates a smooth transition between two or more colors.

1. Linear Gradient

A linear gradient changes colors along a straight line.

background: linear-gradient(red, blue);

Direction:

background: linear-gradient(to right, red, blue);

Multiple Colors:

background: linear-gradient( to right, red, yellow, blue );

2. Radial Gradient

A radial gradient spreads outward from a central point.

background: radial-gradient(circle, red, blue);

3. Conic Gradient

A conic gradient rotates colors around a center point.

background: conic-gradient( red, yellow, green, blue, red );

12. Background Shorthand

The background property can combine multiple background properties into a single declaration.

Example:

background: #222 url("hero.jpg") no-repeat center / cover;

This can represent:

  • Background color
  • Background image
  • Background repeat
  • Background position
  • Background size

CSS Box Model

1. Content

The content is the actual information inside an HTML element.

Content can be text, images, buttons, other elements, etc.

Example:

.box {
  width: 300px;
  height: 150px;
}

Here, width and height define the size of the content area when using the default box-sizing: content-box.

2. Padding

Padding is the space between the content and the border.

Syntax:

padding: 20px;

Individual Sides:

padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

Shorthand:

padding: 10px 20px 30px 40px;
  • 10px → top
  • 20px → right
  • 30px → bottom
  • 40px → left

Padding increases the space inside the element.

3. Border

The border surrounds the content and padding.

Syntax:

border: 2px solid black;

Border Components:

  • 2px → border width
  • solid → border style
  • black → border color

Different Border Styles:

border: 2px solid red;
border: 2px dashed blue;
border: 2px dotted green;
border: 2px double black;

Rounded Border:

border-radius: 10px;

4. Margin

Margin is the space outside an element's border.

Syntax:

margin: 20px;

Individual Sides:

margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;

Auto Margin:

margin: 0 auto;

margin: 0 auto is commonly used to horizontally center a block element when it has a defined width.

Important:

Margin creates space outside the element, while padding creates space inside the element.

5. box-sizing

The box-sizing property controls how the total width and height of an element are calculated.

1. content-box

This is the default value.

box-sizing: content-box;

With content-box, the declared width applies only to the content.

2. border-box

box-sizing: border-box;

With border-box, the declared width includes the content, padding, and border.

Common CSS Reset:

* {
  box-sizing: border-box;
}

This makes width and height calculations easier and more predictable.

6. width

The width property sets the width of an element.

Example:

width: 300px;

Percentage:

width: 50%;

Viewport:

width: 50vw;

Width can use different units such as px, %, rem, and vw.

7. height

The height property sets the height of an element.

Example:

height: 200px;

Viewport Height:

height: 100vh;

100vh means 100% of the viewport height.

8. min-width

The min-width property defines the minimum width an element is allowed to have.

Example:

.box {
  min-width: 300px;
}

The element will not become narrower than 300px.

Common Use:

Useful for preventing cards, inputs, buttons, and containers from becoming too narrow.

9. max-width

The max-width property defines the maximum width an element can reach.

Example:

.container {
  max-width: 1200px;
  margin: 0 auto;
}

This is commonly used for responsive website containers.

Responsive Example:

.container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
}

10. min-height

The min-height property defines the minimum height of an element.

Example:

.card {
  min-height: 200px;
}

The element can grow larger if its content requires more space.

11. max-height

The max-height property defines the maximum height an element can reach.

Example:

.box {
  max-height: 300px;
}

If the content becomes larger than the allowed height, the overflow property can control what happens.

12. overflow

The overflow property controls what happens when content exceeds the size of its container.

1. visible

overflow: visible;

Content is allowed to appear outside the element. This is the default.

2. hidden

overflow: hidden;

Extra content is clipped and not displayed.

3. scroll

overflow: scroll;

Scrollbars are provided so the hidden content can be accessed.

4. auto

overflow: auto;

Scrollbars appear when they are needed.

Axis-specific Overflow:

overflow-x: auto;
overflow-y: hidden;

13. Complete Box Model

Every HTML element can be understood as a rectangular box consisting of four main parts:

Content
  • Content → actual content
  • Padding → space around content
  • Border → surrounds padding and content
  • Margin → space outside the border

Order:

Margin → Border → Padding → Content

CSS Typography

1. font-family

The font-family property specifies the font used to display text.

Syntax:

font-family: Arial, sans-serif;

Example:

p {
  font-family: Arial, sans-serif;
}

Font Fallback:

Multiple fonts can be provided. If the first font is unavailable, the browser tries the next one.

font-family: "Helvetica Neue", Arial, sans-serif;

Common Font Families:

  • Arial
  • Verdana
  • Georgia
  • Times New Roman
  • Courier New
  • sans-serif
  • serif
  • monospace

2. font-size

The font-size property controls the size of text.

Example:

h1 {
  font-size: 40px;
}

Common Units:

  • px → fixed pixel size
  • em → relative to the parent font size
  • rem → relative to the root font size
  • % → percentage-based size
  • vw → relative to viewport width

Example:

font-size: 20px;
font-size: 1.5rem;
font-size: 2em;

3. font-weight

The font-weight property controls how thick or bold the text appears.

Keyword Values:

font-weight: normal;
font-weight: bold;

Numeric Values:

font-weight: 100;
font-weight: 300;

font-weight: 500;
font-weight: 600;
font-weight: 700;
font-weight: 900;
  • 400 → commonly normal

The font-style property controls whether text is normal, italic, or oblique.

  • normal → normal text

line-height: 30px;

Recommended:

6. letter-spacing

Example:

h1 {

Negative Value:

letter-spacing: -1px;

7. word-spacing

The word-spacing property controls the space between words.

Example:

p {
  word-spacing: 10px;

Positive values increase the space between words.

Negative Value:

word-spacing: -2px;

8. text-align

The text-align property controls the horizontal alignment of inline content inside an element.

Common Values:

  • left

  • right

  • start
  • end

text-align: justify;

h1 {

9. text-decoration

10. text-transform

Common Values:

CSS Layout — Flexbox

1. What is Flexbox?

Flexbox, short for Flexible Box Layout, is a CSS layout system used to arrange elements in a row or column.

Flexbox makes it easier to align, distribute, resize, and position elements inside a container.

Important Terms:

  • Flex container → parent element
  • Flex items → direct children of the container
  • Main axis → primary direction of the flex layout
  • Cross axis → direction perpendicular to the main axis

Example:

.container {
  display: flex;
}

The direct children of .container become flex items.

2. display: flex

The display: flex property turns an element into a flex container.

Example:

.container {
  display: flex;
}

HTML:

<div class="container">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

By default, flex items are arranged horizontally.

3. flex-direction

The flex-direction property defines the direction of the main axis.

Values:

  • row → left to right (default)
  • row-reverse → right to left
  • column → top to bottom
  • column-reverse → bottom to top

Examples:

.container {
  display: flex;
  flex-direction: row;
} .container {
  display: flex;
  flex-direction: column;
}

4. justify-content

The justify-content property controls how flex items are distributed along the main axis.

Common Values:

  • flex-start → items at the start
  • flex-end → items at the end
  • center → items in the center
  • space-between → equal space between items
  • space-around → space around items
  • space-evenly → equal space everywhere

Example:

.container {
  display: flex;
  justify-content: center;
}

If flex-direction: row, the main axis is horizontal. Therefore, justify-content controls horizontal distribution.

5. align-items

The align-items property aligns flex items along the cross axis.

Common Values:

  • stretch → stretches items (default in many row layouts)
  • flex-start → cross-axis start
  • flex-end → cross-axis end
  • center → center
  • baseline → aligns text baselines

Example:

.container {
  display: flex;
  align-items: center;
}

With flex-direction: row, this generally controls vertical alignment.

6. align-content

The align-content property controls the spacing and alignment of multiple flex lines along the cross axis.

It generally has an effect only when flex items wrap onto multiple lines and there is extra space in the container.

Common Values:

  • flex-start
  • flex-end
  • center
  • space-between
  • space-around
  • space-evenly
  • stretch

Example:

.container {
  display: flex;
  flex-wrap: wrap;
  align-content: space-between;
}

Important Difference:

  • align-items → aligns items within a flex line
  • align-content → aligns multiple flex lines

7. flex-wrap

The flex-wrap property determines whether flex items should stay on one line or move onto multiple lines.

Values:

  • nowrap → all items remain on one line
  • wrap → items move to new lines
  • wrap-reverse → lines wrap in the reverse cross-axis direction

Example:

.container {
  display: flex;
  flex-wrap: wrap;
}

flex-wrap: wrap is very useful for responsive card layouts.

8. gap

The gap property creates space between flex items.

Example:

.container {
  display: flex;
  gap: 20px;
}

Separate Row and Column Gaps:

gap: 10px 20px;
  • 10px → row gap
  • 20px → column gap

gap is often cleaner than adding margins to individual flex items.

9. flex-grow

The flex-grow property determines how much a flex item can grow relative to other flex items when extra space is available.

Example:

.item {
  flex-grow: 1;
}

Example with Different Values:

.item1 { flex-grow: 1; }
.item2 { flex-grow: 2; }

If extra space is available, the second item gets twice the growth share of the first item, assuming comparable starting conditions.

Common Pattern:

.item {
  flex-grow: 1;
}

This can make multiple items share available space.

10. flex-shrink

The flex-shrink property determines how much a flex item can shrink when there is not enough space.

Example:

.item {
  flex-shrink: 1;
}

Prevent Shrinking:

.item {
  flex-shrink: 0;
}

A value of 0 prevents the item from shrinking due to flex sizing.

Example:

.logo {
  flex-shrink: 0;
}

11. flex-basis

The flex-basis property defines the initial main-axis size of a flex item before available space is distributed.

Example:

.item {
  flex-basis: 200px;
}

In a row layout, this generally represents the item's initial width. In a column layout, it generally represents the initial height.

Common Values:

flex-basis: 200px;
flex-basis: 30%;
flex-basis: auto;

12. align-self

The align-self property allows one flex item to override the container's align-items value.

Example:

.item {
  align-self: flex-end;
}

Common Values:

  • auto
  • flex-start
  • flex-end
  • center
  • stretch
  • baseline

Unlike align-items, which affects all flex items, align-self affects an individual item.

13. order

The order property controls the visual order of flex items.

The default value is 0.

Example:

.item1 {
  order: 2;
}

.item2 {
  order: 1;
}

The item with the smaller order value appears first.

Example:

.first { order: 3; }
.second { order: 1; }
.third { order: 2; }

Visual order becomes: second → third → first.

Important: Changing visual order does not necessarily change the underlying DOM order. Be careful with accessibility and keyboard navigation.

14. Main Axis & Cross Axis

Understanding the axes is one of the most important concepts in Flexbox.

When flex-direction is row:

  • Main axis → horizontal
  • Cross axis → vertical
  • justify-content → main axis
  • align-items → cross axis

When flex-direction is column:

  • Main axis → vertical
  • Cross axis → horizontal
  • justify-content → vertical direction
  • align-items → horizontal direction

Easy Rule:

justify-content → Main Axis
align-items → Cross Axis

15. Complete Flexbox Example

HTML:

<div class="container">
  <div class="item">Item 1</div>
  <div class="item">Item 2</div>
  <div class="item">Item 3</div>
</div>

CSS:

.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  flex-wrap: wrap;
  gap: 20px;
}

.item {
  flex-grow: 1;
  flex-basis: 200px;
}

16. Flexbox Quick Reference

  • display: flex → creates flex container
  • flex-direction → sets main-axis direction
  • justify-content → aligns items on main axis
  • align-items → aligns items on cross axis
  • align-content → aligns multiple flex lines
  • flex-wrap → controls wrapping
  • gap → creates space between items
  • flex-grow → controls growth
  • flex-shrink → controls shrinking
  • flex-basis → initial main-axis size
  • align-self → individually aligns an item
  • order → changes visual item order

Notes

Note: Flexbox is primarily designed for one-dimensional layouts: a row or a column.

Note: display: flex turns an element into a flex container and its direct children into flex items.

Note: justify-content works on the main axis.

Note: align-items works on the cross axis.

Note: align-content matters when there are multiple flex lines.

Note: flex-grow, flex-shrink, and flex-basis control how flex items use available space.

Note: gap is useful for consistent spacing between flex items.

Note: align-self can override align-items for an individual item.

Note: Flexbox is commonly used for navbars, cards, buttons, headers, forms, and responsive layouts.

CSS Grid

1. What is CSS Grid?

CSS Grid is a two-dimensional CSS layout system used to arrange elements into rows and columns.

Grid is especially useful for complex page layouts such as dashboards, galleries, admin panels, and responsive card layouts.

Flexbox vs Grid:

  • Flexbox → primarily one-dimensional layout (row or column)
  • Grid → two-dimensional layout (rows and columns)

Basic Example:

.container {
  display: grid;
}

2. display: grid

The display: grid property turns an element into a grid container.

Example:

.container {
  display: grid;
}

HTML:

<div class="container">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</div>

Grid items are the direct children of the grid container.

3. grid-template-columns

The grid-template-columns property defines the number and size of columns in a grid.

Two Equal Columns:

.container {
  display: grid;
  grid-template-columns: 1fr 1fr;
}

1fr 1fr creates two equal columns.

Three Equal Columns:

grid-template-columns: 1fr 1fr 1fr;

Different Sizes:

grid-template-columns: 200px 1fr 2fr;

The fr unit represents a fraction of the available grid space.

4. grid-template-rows

The grid-template-rows property defines the size of grid rows.

Example:

.container {
  display: grid;
  grid-template-rows: 100px 200px 100px;
}

This creates three rows with heights of 100px, 200px, and 100px.

Using fr:

grid-template-rows: 1fr 2fr 1fr;

5. gap

The gap property creates space between grid rows and columns.

Example:

.container {
  display: grid;
  gap: 20px;
}

Different Row and Column Gaps:

row-gap: 10px;
column-gap: 20px;

Or use the shorthand:

gap: 10px 20px;
  • 10px → row gap
  • 20px → column gap

6. grid-column

The grid-column property controls where a grid item starts and ends across columns.

Example:

.item {
  grid-column: 1 / 3;
}

The item starts at column line 1 and ends at column line 3, spanning two column tracks.

Using span:

grid-column: span 2;

This makes the item span two columns from its automatic starting position.

Full Width:

grid-column: 1 / -1;

This commonly makes an item span from the first grid line to the last.

7. grid-row

The grid-row property controls where an item starts and ends across rows.

Example:

.item {
  grid-row: 1 / 3;
}

The item spans from row line 1 to row line 3.

Using span:

grid-row: span 2;

This makes the item span two rows.

8. grid-area

The grid-area property can specify the row and column position of a grid item.

Using Line Numbers:

grid-area: 1 / 1 / 3 / 3;

The four values represent:

  • Row start
  • Column start
  • Row end
  • Column end

Named Grid Areas:

.layout {
  display: grid;
  grid-template-areas:
    "header header"
    "sidebar main"
    "footer footer";
}

.header {
  grid-area: header;
}

.sidebar {
  grid-area: sidebar;
}

.main {
  grid-area: main;
}

.footer {
  grid-area: footer;
}

9. repeat()

The repeat() function makes repeated grid tracks easier to write.

Without repeat():

grid-template-columns: 1fr 1fr 1fr 1fr;

With repeat():

grid-template-columns: repeat(4, 1fr);

Both create four equal columns.

Example:

grid-template-columns: repeat(3, 200px);

This creates three columns, each 200px wide.

10. minmax()

The minmax() function defines a minimum and maximum size for a grid track.

Syntax:

minmax(minimum, maximum)

Example:

grid-template-columns: repeat(3, minmax(200px, 1fr));

Each column can be at least 200px and can grow up to one fraction of the available space.

Responsive Example:

grid-template-columns: repeat( auto-fit, minmax(250px, 1fr) );

11. auto-fit

auto-fit automatically fits as many columns as possible into the available space and can collapse empty tracks.

Example:

.container {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

This is a very common pattern for responsive card grids.

Use Cases:

  • Product cards
  • Portfolio cards
  • Photo galleries
  • Dashboard widgets

12. auto-fill

auto-fill creates as many grid tracks as can fit within the available space, including empty tracks when applicable.

Example:

.container {
  display: grid;
  grid-template-columns:
    repeat(auto-fill, minmax(250px, 1fr));
  gap: 20px;
}

auto-fit vs auto-fill:

  • auto-fit → fits available items and collapses empty tracks
  • auto-fill → keeps as many possible tracks, including empty tracks when space allows

With flexible tracks such as minmax(), the difference is most noticeable when there are fewer items than the number of possible columns.

13. Responsive Grid

CSS Grid can create responsive layouts without manually specifying a different number of columns for every screen size.

Example:

.cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

As the available width changes, the number of columns can automatically adjust.

  • display: grid → creates a grid container
  • grid-template-columns → defines columns
  • grid-template-rows → defines rows
  • gap → creates space between grid items
  • grid-column → controls column placement
  • grid-row → controls row placement

  • auto-fill → fills as many possible tracks as space allows

Most Useful Responsive Pattern:

Notes

Note: minmax() is very useful for responsive layouts.

CSS Responsive Design

1. What is Responsive Design?

Responsive Design is a web design approach that makes a website automatically adapt to different screen sizes and devices.

A responsive website should work properly on:

  • Mobile phones
  • Tablets
  • Laptops
  • Desktop computers
  • Large screens

Goal:

The layout, text, images, navigation, and other components should remain usable and readable across different screen sizes.

Example:

width: 100%;
max-width: 1200px;

2. Mobile-First Design

Mobile-first design means designing the website for smaller screens first and then adding styles for larger screens.

Basic Approach:

/* Mobile styles */
.container {
  width: 100%;
}

/* Larger screens */
@media (min-width: 768px) {
  .container {
    width: 80%;
  }
}

Advantages:

  • Works well for small screens first
  • Encourages simpler layouts
  • Improves mobile usability
  • Styles progressively enhance for larger screens

3. Media Queries

Media queries allow CSS to apply different styles based on conditions such as viewport width.

Syntax:

@media (condition) {
  /* CSS rules */
}

Example:

@media (max-width: 600px) {
  body {
    background-color: lightblue;
  }
}

The styles inside the media query apply when the viewport is 600px wide or narrower.

Min-width Example:

@media (min-width: 768px) {
  .container {
    display: grid;
  }
}

4. Breakpoints

Breakpoints are viewport widths where the layout changes to provide a better experience.

Example Breakpoints:

/* Small devices */
@media (min-width: 576px) { ... }

/* Medium devices */
@media (min-width: 768px) { ... }

/* Large devices */
@media (min-width: 992px) { ... }

/* Extra large devices */
@media (min-width: 1200px) { ... }

These are common example values, not mandatory standards. Choose breakpoints based on when your actual layout needs to change.

Best Practice:

Do not choose breakpoints only because a device has a particular name. Choose them based on where your content or layout starts to look uncomfortable.

5. Responsive Units

Responsive units allow sizes to adapt based on the parent element, root font size, or viewport.

  • % → relative to a containing dimension
  • em → relative to the relevant element's font size
  • rem → relative to the root element's font size
  • vw → viewport width
  • vh → viewport height

6. % — Percentage

The percentage unit is relative to a relevant containing dimension.

Example:

.container {
  width: 80%;
}

A percentage is commonly used for flexible widths.

Example:

.image {
  width: 100%;
  height: auto;
}

7. em

The em unit is relative to the font size of the relevant element, commonly its parent for inherited sizing.

Example:

.parent {
  font-size: 20px;
}

.child {
  font-size: 1.5em;
}

In this example, the child font size is 30px because 1.5 × 20px = 30px.

Common Use:

em is useful when you want dimensions to scale with an element's typography.

8. rem

The rem unit is relative to the font size of the root element, usually <html>.

Example:

html {
  font-size: 16px;
}

.title {
  font-size: 2rem;
}

If the root font size is 16px, 2rem equals 32px.

Common Use:

rem is commonly used for scalable typography, spacing, and component dimensions.

9. vw

vw stands for viewport width.

1vw represents 1% of the viewport's width.

Example:

.hero-title {
  font-size: 5vw;
}

The font size changes as the viewport width changes.

10. vh

vh stands for viewport height.

1vh represents 1% of the viewport's height.

Example:

.hero {
  min-height: 100vh;
}

This makes the hero section at least as tall as the viewport.

11. clamp()

The clamp() function allows a value to grow or shrink between a minimum and maximum limit.

Syntax:

clamp(minimum, preferred, maximum)

Example:

h1 {
  font-size: clamp(2rem, 5vw, 4rem);
}
  • 2rem → minimum size
  • 5vw → preferred flexible size
  • 4rem → maximum size

This is extremely useful for responsive typography.

Responsive Container Example:

.container {
  padding: clamp(1rem, 3vw, 3rem);
}

12. Responsive Images

Responsive images automatically scale to fit their available container without breaking the layout.

Basic CSS:

img {
  max-width: 100%;
  height: auto;
}

Meaning:

  • max-width: 100% → image cannot exceed its container
  • height: auto → preserves the image's aspect ratio

Responsive Card Image:

.card img {
  width: 100%;
  height: 220px;
  object-fit: cover;
}

HTML:

<img
  src="image.jpg"
  alt="Product image"
/>

13. Responsive Typography

Responsive typography allows text to adapt to different screen sizes while remaining readable.

Using clamp():

h1 {
  font-size: clamp(2rem, 5vw, 4rem);
}

p {
  font-size: clamp(1rem, 2vw, 1.25rem);
  line-height: 1.6;
}

Using Media Queries:

h1 {
  font-size: 40px;
}

@media (max-width: 600px) {
  h1 {
    font-size: 28px;
  }
}

Best Practices:

  • Keep body text readable on small screens.

CSS Cascade & Specificity

1. CSS Cascade

The CSS Cascade is the process the browser uses to decide which CSS rule should be applied when multiple rules target the same element.

When multiple rules conflict, the browser considers factors such as importance, origin, specificity, and source order.

Example:

p {
  color: red;
}

p {
  color: blue;
}

If both rules have the same relevance and specificity, the later rule wins.

Simple Idea:

Multiple Rules
↓
Cascade Decides
↓
Winning Rule
↓
Applied Style

2. Specificity

Specificity is a scoring system used by CSS to determine which selector is more specific when multiple applicable rules conflict.

General Specificity Order:

  1. Inline styles
  2. ID selectors
  3. Class, attribute, and pseudo-class selectors
  4. Element and pseudo-element selectors

Example:

p { color: green; }
.text { color: blue; }
#title { color: red; }

If all three target the same element, the ID selector is more specific than the class and element selectors.

3. Inline Specificity

An inline style is written directly inside the HTML style attribute.

Example:

<p style="color: red;">
  Hello CSS
</p>

Normal inline styles have very high specificity compared with ordinary author stylesheet selectors.

Comparison:

p { color: blue; }

.text { color: green; }

#message { color: purple; }

An inline declaration such as style="color: red" will normally win over these rules when they all set the same property.

4. ID Specificity

An ID selector targets an element using its unique id attribute.

Example:

#heading {
  color: red;
}

HTML:

<h1 id="heading">Hello</h1>

An ID selector has higher specificity than class and element selectors.

5. Class Specificity

A class selector targets elements using a class name.

Example:

.heading {
  color: blue;
}

HTML:

<h1 class="heading">Hello</h1>

Classes have lower specificity than IDs but higher specificity than ordinary element selectors.

6. Element Specificity

Element selectors target HTML elements directly.

Example:

p {
  color: green;
}

Element selectors have lower specificity than class and ID selectors.

Other Examples:

h1 { ... }
div { ... }
button { ... }
p { ... }

7. Specificity Calculation

Specificity can be understood using four components:

Inline | ID | Class/Attribute/Pseudo-class | Element/Pseudo-element

Example 1:

p { color: red; }

Specificity: 0-0-0-1

Example 2:

.text { color: blue; }

Specificity: 0-0-1-0

Example 3:

#title { color: green; }

Specificity: 0-1-0-0

Example 4:

#title .text p {
  color: purple;
}

Specificity: 0-1-1-1

Important Rule:

Compare specificity from left to right. A larger value in a more significant category wins; you do not simply add all the digits together.

8. Specificity Comparison Examples

Example 1:

p { color: red; }
.message { color: blue; }

Winner: .message

Example 2:

.message { color: blue; }
#welcome { color: green; }

Winner: #welcome

Example 3:

#welcome { color: green; }
#welcome.message { color: purple; }

Winner: #welcome.message because it has one ID plus one class.

Example 4:

.card p { color: red; }
p { color: blue; }

Winner: .card p

It contains one class selector and one element selector.

9. !important

The !important flag gives a declaration special priority in the cascade.

Example:

p {
  color: red !important;
}

This can override normal declarations, even declarations with greater ordinary specificity.

Example:

#message {
  color: blue;
}

p {
  color: red !important;
}

The red declaration is important, so it can beat the normal ID declaration.

Best Practice:

Avoid unnecessary use of !important. Excessive use can make CSS difficult to maintain and override.

Note: !important does not simply mean "highest specificity"; importance is a separate part of the cascade.

10. Inheritance

Inheritance means some CSS properties can automatically pass from a parent element to its descendants.

Example:

body {
  color: blue;
  font-family: Arial, sans-serif;
}

Many descendant elements can inherit these properties unless another rule overrides them.

Commonly Inherited Properties:

  • color
  • font-family
  • font-size
  • line-height
  • text-align

Example:

.parent {
  color: red;
}

.child {
  /* color can be inherited */
}

Force Inheritance:

color: inherit;

This explicitly tells the property to use the inherited value.

11. CSS Source Order

Source order means the order in which CSS declarations appear.

When competing declarations have the same importance and specificity, the later declaration wins.

Example:

p {
  color: red;
}

p {
  color: blue;
}

The paragraph becomes blue because both selectors have the same specificity and the second rule appears later.

Another Example:

.title {
  color: red;
}

.title {
  color: blue;
}

Both selectors have the same specificity, so the second declaration wins.

12. Shorthand Properties

A shorthand property allows multiple related CSS properties to be written in a single declaration.

Margin Shorthand:

margin: 10px 20px 30px 40px;
  • Top → 10px
  • Right → 20px
  • Bottom → 30px
  • Left → 40px

Padding Shorthand:

padding: 10px 20px;
  • Top & Bottom → 10px
  • Left & Right → 20px

Border Shorthand:

border: 2px solid red;

13. Longhand Properties

Longhand properties specify individual CSS properties separately.

Shorthand:

margin: 10px 20px 30px 40px;

Equivalent Longhand:

margin-top: 10px;
margin-right: 20px;
margin-bottom: 30px;
margin-left: 40px;

Border Longhand:

border-width: 2px;
border-style: solid;
border-color: red;

14. Shorthand vs Longhand

Shorthand:

padding: 10px 20px;

Shorter and convenient when setting several related values.

Longhand:

padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;

More explicit and useful when only one specific side needs to be changed.

Important:

A later shorthand declaration can reset related longhand values.

Example:

margin-top: 50px;
margin: 10px;

The later margin shorthand resets all four margin sides to 10px.

15. Specificity Calculation Practice

Example:

#container .card p {
  color: red;
}

.card p {
  color: blue;
}

p {
  color: green;
}

Specificity:

  • #container .card p → 0-1-1-1
  • .card p → 0-0-1-1
  • p → 0-0-0-1

Therefore, #container .card p wins because it has the highest specificity.

  2. Specificity

  3. Source order

1. Normal Document Flow

Elements are placed according to their type and the layout rules of their parent.

Block Elements:

Block elements normally start on a new line and take up the available width.

Examples:

<div>Box 1</div>
<div>Box 2</div>
<p>Paragraph</p>

Inline Elements:

Inline elements normally flow within the same line as surrounding text, subject to available space.

Examples:

<span>Hello</span>
<a href="#">Link</a>
<strong>Bold</strong>

Important:

Elements with position: absolute or position: fixed are removed from normal document flow.

3. Containing Block

A containing block is the reference box used to calculate the position and size of certain positioned elements.

Understanding the containing block is especially important when using position: absolute.

Common Pattern:

.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 10px;
  right: 10px;
}

Here, the positioned parent establishes a containing block for the absolutely positioned child.

HTML:

  <div class="child">Badge</div>
</div>

4. top

The top property specifies an offset from the relevant containing edge for a positioned element.

Example:

.box {
  position: relative;
  top: 20px;
}

With relative positioning, the element is visually shifted downward by 20px from its normal position.

Absolute Example:

.box {
  position: absolute;
  top: 20px;
}

The exact reference depends on the element's containing block.

5. right

The right property specifies an offset from the relevant right edge for a positioned element.

Example:

.box {
  position: absolute;
  right: 20px;
}

This commonly places an absolutely positioned element 20px from the right edge of its containing block.

Common Use:

.notification {
  position: absolute;
  top: 10px;
  right: 10px;
}

6. bottom

The bottom property specifies an offset from the relevant bottom edge.

Example:

.button {
  position: fixed;
  bottom: 20px;
  right: 20px;
}

This is commonly used for floating action buttons or back-to-top buttons.

7. left

The left property specifies an offset from the relevant left edge.

Example:

.sidebar {
  position: fixed;
  left: 0;
  top: 0;
}

This can position an element against the left side of its positioning reference.

8. Combining top, right, bottom & left

Multiple offsets can be used together to position or stretch an element.

Example:

.overlay {
  position: absolute;
  top: 0;
  right: 0;
  bottom: 0;
  left: 0;
}

This commonly makes the element fill the containing block, subject to the normal positioning rules.

Modern Shorthand:

inset: 0;

inset: 0 is equivalent to setting top, right, bottom, and left to 0.

9. Stacking Context

A stacking context is a three-dimensional ordering context that determines how elements are painted relative to one another.

It is one of the main concepts behind understanding why z-index sometimes appears not to work.

Simple Visualization:

Higher Layer
───────────────────
Modal

Middle Layer
───────────────────
Navbar

Lower Layer
───────────────────
Page Content

Common Ways Stacking Contexts Can Be Created:

  • The root element creates the root stacking context.
  • A positioned element with a non-auto z-index can create one.
  • Certain properties such as opacity less than 1 can create one.
  • Certain transforms, filters, isolation, and other CSS features can create stacking contexts.

Example:

.modal {
  position: fixed;
  z-index: 1000;
}

The modal participates in stacking according to its stacking context and the contexts around it.

10. z-index

The z-index property controls the stacking order of positioned elements and other elements that participate in stacking contexts.

Example:

.box1 {
  position: absolute;
  z-index: 1;
}

.box2 {
  position: absolute;
  z-index: 2;
}

When the boxes overlap within the same stacking context, box2 will generally appear above box1.

Common Values:

z-index: 1;
z-index: 10;
z-index: 100;
z-index: 999;
z-index: -1;

Important:

A larger z-index does not automatically place an element above everything on the page. Stacking contexts determine which elements can actually be compared.

11. z-index Example

HTML:

<div class="container">
  <div class="red-box">Red</div>
  <div class="blue-box">Blue</div>
</div>

CSS:

.container {
  position: relative;
  height: 200px;
}

.red-box {
  position: absolute;
  top: 30px;
  left: 30px;
  z-index: 1;
}

.blue-box {
  position: absolute;
  top: 60px;
  left: 60px;
  z-index: 2;
}

Because blue-box has a higher z-index within the same stacking context, it appears above the red box when they overlap.

  • normal flow → default arrangement of elements
  • position: relative → keeps its space and can be visually offset

  • position: sticky → remains in flow and can stick while scrolling
  • top → controls top-side offset
  • right → controls right-side offset

  • left → controls left-side offset
  • inset → shorthand for top/right/bottom/left

Note: Normal document flow is the default layout behavior of HTML elements.

Note: relative keeps an element in normal flow while allowing visual offsets.

Note: Absolutely positioned elements are removed from normal flow.

Note: A positioned ancestor is commonly used to establish the containing block for an absolutely positioned child.

Note: top, right, bottom, and left are offsets used with positioned elements.

CSS Functions, Modern CSS & Accessibility

11. 🧮 CSS Functions

CSS functions are special expressions that allow CSS to calculate values, reuse variables, create colors, load resources, and build responsive layouts.

Common CSS Functions:

  • calc() → performs calculations
  • min() → chooses the smallest value
  • max() → chooses the largest value
  • clamp() → creates a minimum, preferred, and maximum value
  • var() → uses CSS variables
  • rgb() → creates RGB colors
  • hsl() → creates HSL colors
  • url() → references external resources

1. calc()

calc() performs mathematical calculations directly inside CSS property values.

Syntax:

calc(expression)

Example:

width: calc(100% - 40px);

This means: 100% width minus 40px.

Another Example:

height: calc(100vh - 80px);

Useful when a page contains a fixed-height header.

Supported Operators:

+    Addition
-    Subtraction
*    Multiplication
/    Division

Real-World Example:

.content {
  width: calc(100% - 250px);
}

Useful for layouts containing a sidebar and main content.

2. min()

min() returns the smallest value from the provided arguments.

Example:

width: min(90%, 1200px);

The element will use whichever is smaller: 90% or 1200px.

Real-World Example:

.container {
  width: min(90%, 1200px);
  margin: auto;
}

This is commonly used to create responsive containers.

3. max()

max() returns the largest value from the provided arguments.

Example:

width: max(300px, 50%);

The width will be whichever is larger: 300px or 50%.

Useful Example:

padding: max(20px, 5vw);

This ensures the padding does not become smaller than 20px.

4. clamp()

clamp() creates a responsive value with a minimum, preferred, and maximum value.

Syntax:

clamp(minimum, preferred, maximum)

Example:

font-size: clamp(24px, 5vw, 64px);
  • Minimum → 24px
  • Preferred → 5vw
  • Maximum → 64px

This is extremely useful for responsive typography.

Responsive Heading:

h1 {
  font-size: clamp(2rem, 5vw, 5rem);
}

5. var()

var() is used to access a CSS custom property.

Define Variable:

:root {
  --primary-color: #2563eb;
  --spacing: 20px;
}

Use Variable:

.button {
  background: var(--primary-color);
  padding: var(--spacing);
}

Fallback Value:

color: var(--text-color, black);

If --text-color is unavailable, the fallback black is used.

6. rgb()

rgb() creates colors using Red, Green, and Blue components.

Syntax:

rgb(red, green, blue)

Example:

color: rgb(255, 0, 0);

This creates red.

Another Example:

background: rgb(30, 64, 175);

Modern Alpha Example:

background: rgb(0 0 0 / 50%);

The final value controls transparency.

7. hsl()

hsl() represents colors using Hue, Saturation, and Lightness.

Syntax:

hsl(hue, saturation, lightness)

Example:

color: hsl(220, 80%, 50%);
  • Hue → 220°
  • Saturation → 80%
  • Lightness → 50%

Modern Alpha Example:

background: hsl(220 80% 50% / 50%);

8. url()

url() specifies an external resource, commonly an image.

Background Image:

background-image: url("image.jpg");

Font:

@font-face {
  font-family: "MyFont";
  src: url("font.woff2");
}

Common Uses:

  • Background images
  • Fonts
  • Cursors
  • Other CSS resources

12. 🚀 Modern CSS

Modern CSS provides powerful features that make responsive layouts, component styling, scrolling, visual effects, and advanced selectors easier to build.

9. CSS Nesting

CSS nesting allows related selectors to be written inside another CSS rule.

Example:

.card {
  padding: 20px;

  h2 {
    color: blue;
  }

  &:hover {
    transform: translateY(-5px);
  }
}

The & represents the parent selector in nested selectors.

Traditional CSS:

.card h2 { color: blue; }
.card:hover { transform: translateY(-5px); }

10. aspect-ratio

The aspect-ratio property controls the preferred width-to- height ratio of an element.

Example:

.video {
  width: 100%;
  aspect-ratio: 16 / 9;
}

This is useful for videos, images, cards, and media containers.

Common Ratios:

16 / 9
4 / 3
1 / 1
3 / 2

11. object-fit

object-fit controls how replaced content such as an image or video fits inside its box.

cover:

img {
  width: 300px;
  height: 200px;
  object-fit: cover;
}

cover fills the box while preserving the aspect ratio. Some content may be cropped.

contain:

object-fit: contain;

contain keeps the entire content visible while preserving its aspect ratio.

Other Values:

  • fill
  • none
  • scale-down

12. object-position

object-position controls the position of replaced content inside its box when using properties such as object-fit.

Example:

img {
  object-fit: cover;
  object-position: center;
}

Common Values:

center
top
bottom
left
right

Example:

object-position: top center;

13. scroll-behavior

scroll-behavior controls the scrolling behavior when scrolling is triggered by navigation or CSSOM scrolling.

Example:

html {
  scroll-behavior: smooth;
}

This can make anchor navigation move smoothly instead of jumping instantly.

Values:

  • auto
  • smooth

14. Scroll Snap

Scroll snap allows scrolling containers to snap to defined positions.

Container:

.slider {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}

Child:

.slide {
  scroll-snap-align: start;
  flex: 0 0 100%;
}

Common Uses:

  • Image sliders
  • Mobile carousels
  • Horizontal cards
  • Full-page sections

15. backdrop-filter

backdrop-filter applies graphical effects to the area behind an element.

Glass Effect:

.glass {
  background: rgb(255 255 255 / 20%);
  backdrop-filter: blur(10px);
}

This is commonly used for modern glassmorphism interfaces.

Example:

backdrop-filter: blur(10px) saturate(150%);

A translucent background is normally used so that the filtered backdrop can be seen.

16. accent-color

accent-color allows you to customize the accent color of certain native form controls.

Example:

input {
  accent-color: #2563eb;
}

It can affect controls such as checkboxes, radio buttons, and progress indicators depending on browser support.

17. appearance

The appearance property controls the platform-specific styling of certain form controls.

Example:

button {
  appearance: none;
}

This can remove or change the browser's native appearance so you can create custom styling.

Important:

When replacing native control styling, make sure the resulting control remains usable and accessible.

18. :is()

:is() groups multiple selectors into one selector list.

Without :is():

.card h1,
.card h2,
.card h3 {
  color: blue;
}

With :is():

.card :is(h1, h2, h3) {
  color: blue;
}

This can make selector lists shorter and easier to maintain.

Specificity: The specificity of :is() is based on the most specific selector in its argument list.

19. :where()

:where() also groups selectors, but its specificity is always zero.

Example:

.card :where(h1, h2, h3) {
  margin-bottom: 10px;
}

This makes :where() useful for writing low-specificity default styles that are easy to override.

Difference:

:is() → keeps the highest specificity of its arguments
:where() → always has zero specificity

20. :has()

:has() selects an element based on whether it contains a matching relative selector.

Example:

.card:has(img) {
  border: 2px solid blue;
}

This selects cards that contain an image.

Form Example:

.form-group:has(input:invalid) {
  border-color: red;
}

This can style a parent based on the state of a descendant.

Important:

:has() is sometimes described as a "parent selector", but technically it is a relational pseudo-class that matches an element based on a relative selector.

13. ♿ CSS Accessibility

CSS accessibility means designing styles so that interfaces remain usable for people with different visual, motor, and cognitive needs.

21. :focus

:focus selects an element when it has keyboard focus or another form of focus.

Example:

input:focus {
  border-color: blue;
  outline: 3px solid lightblue;
}

Focus styling is especially important for keyboard users.

22. :focus-visible

:focus-visible allows you to apply focus styles when the browser determines that a visible focus indicator would be useful, especially during keyboard navigation.

Example:

button:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 3px;
}

Recommended Pattern:

button:focus {
  /* Do not unnecessarily remove focus */
}

button:focus-visible {
  outline: 3px solid blue;
}

23. Color Contrast

Color contrast is the difference in visual appearance between foreground content and its background.

Good contrast makes text, icons, controls, and other important content easier to see.

Bad Example:

background: white;
color: #ddd;

Light gray text on a white background can be difficult to read.

Better Example:

background: white;
color: #222;

Important:

  • Do not rely only on color to communicate meaning.
  • Use readable text sizes.
  • Provide sufficient contrast.
  • Check disabled and interactive states carefully.

24. prefers-reduced-motion

prefers-reduced-motion detects when a user has requested reduced motion through their operating system or browser preferences.

Example:

@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

Prefer reducing non-essential motion rather than making the entire interface unusable.

25. Visible Focus Indicators

Interactive elements should have a clearly visible focus indicator when users navigate using a keyboard.

Good Example:

a:focus-visible,
button:focus-visible,
input:focus-visible {
  outline: 3px solid #2563eb;
  outline-offset: 3px;
}

Do not blindly use:

outline: none;

Removing the default focus indicator without replacing it can make keyboard navigation difficult.

26. Accessible Hover States

Hover effects should not be the only way to understand or operate an interactive element.

Example:

.button:hover {
  transform: translateY(-2px);
  background: #1d4ed8;
}

.button:focus-visible {
  outline: 3px solid #111;
  outline-offset: 3px;
}

Important:

  • Provide keyboard-accessible focus styles.
  • Do not hide important information only on hover.
  • Ensure touch users can access the same functionality.
  • Use sufficient contrast for hover and focus states.
