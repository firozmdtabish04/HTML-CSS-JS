Links

<a> Tag is used to create hyperlinks in HTML.

Basic Example: <a href="https://www.google.com"> Google </a>

  • <a> → creates a hyperlink
  • href → specifies the destination URL
  • target → specifies where to open the link
  • rel → defines the relationship between the current page and linked page

1. Absolute URL

An absolute URL contains the complete web address.

<a href="https://www.yt.com">yt </a>

2. Relative URL

A relative URL points to a file within the same website or project.

<a href="about.html">About Us</a>

3. target Attribute

The target attribute specifies where the linked page should open.

<a href="https://www.google.com" target="_blank"> Open Google </a>
  • _blank → opens in a new tab
  • _self → opens in the current tab
  • _parent → opens in the parent frame
  • _top → opens in the full window

4. rel Attribute

The rel attribute defines the relationship between the current page and the linked page.

<a href="https://example.com" target="_blank" rel="noopener noreferrer"> Example </a>
  • noopener → prevents the new page from accessing the opener
  • noreferrer → prevents sending the referrer information

5. Email Link

Use mailto: to create an email link.

<a href="mailto:example@gmail.com"> Send Email </a>

6. Telephone Link

Use tel: to create a telephone link.

<a href="tel:+919876543210"> Call Us </a>

7. Internal Page Link

An internal link connects one page of a website to another page.

<a href="about.html"> About Us </a>

8. Anchor Link

An anchor link moves the user to a specific section of the same page.

<a href="#contact"> Go to Contact </a> <h2 id="contact"> Contact Us </h2>

Images

<img> Tag is used to display images on a web page.

Basic Example: <img src="image.jpg" alt="My Image">

  • <img> → displays an image
  • src → specifies the image path or URL
  • alt → provides alternative text for the image
  • width → specifies the image width
  • height → specifies the image height

1. src Attribute

The src attribute specifies the location of the image.

<img src="image.jpg" alt="My Image">

2. alt Attribute

The alt attribute provides alternative text if the image cannot be displayed.

<img src="image.jpg" alt="Beautiful Mountain">

3. width Attribute

The width attribute specifies the width of the image.

<img src="image.jpg" alt="Mountain" width="500">

4. height Attribute

The height attribute specifies the height of the image.

<img src="image.jpg" alt="Mountain" height="300">

5. Image Paths

Images can be loaded using absolute or relative paths.

Relative path:

<img src="images/photo.jpg" alt="Photo">

Absolute URL:

<img src="https://example.com/photo.jp" alt="Photo">

6. Responsive Images

A responsive image automatically adjusts its size according to the available screen width.

<img src="image.jpg" alt="Responsive Image" style="max-width: 100%; height: auto;" >

7. <figure> Element

The <figure> element is used to group an image with related content such as a caption.

<figure> <img src="mountain.jpg" alt="Mountain"> <figcaption>Beautiful Mountain</figcaption> </figure>

8. <figcaption> Element

The <figcaption> element provides a caption or description for the content inside a <figure>.

Tables

HTML tables are used to organize and display data in rows and columns.

1. <table>

The <table> element is used to create an HTML table.

2. <tr>

The <tr> element defines a table row.

3. <th>

The <th> element defines a table header cell. By default, header text is bold and centered.

4. <td>

The <td> element defines a normal table data cell.

5. <thead>

The <thead> element groups the header rows of a table.

6. <tbody>

The <tbody> element groups the main data rows.

7. <tfoot>

The <tfoot> element groups the footer rows of a table.

8. rowspan

The rowspan attribute allows a cell to span multiple rows.

<td rowspan="2">Total</td>

9. colspan

The colspan attribute allows a cell to span multiple columns.

<th colspan="3">Student Details</th>

Forms

HTML forms are used to collect information from users and send that information to a server.

1. <form>

The <form> element is used to create an HTML form.

<form> ... </form>

2. <input>

The <input> element is used to create different types of input fields.

<input type="text">

3. Text Input

type="text" creates a field for entering normal text.

<input type="text" name="username">

4. Email Input

type="email" is used to collect an email address. The browser can check whether the entered value has a valid email format.

<input type="email" name="email">

5. Password Input

type="password" hides the characters entered by the user.

<input type="password" name="password">

6. Number Input

type="number" is used to enter numeric values.

<input type="number" name="age">

7. Date Input

type="date" allows the user to select a date.

<input type="date" name="dob">

8. Radio Button

type="radio" allows the user to select one option from a group of related options.

<input type="radio" name="gender" value="male"> Male

Radio buttons that belong to the same group should have the same name.

9. Checkbox

type="checkbox" allows the user to select one or more options.

<input type="checkbox" name="skills" value="html"> HTML

10. File Input

type="file" allows the user to select a file from their device.

<input type="file" name="resume">

11. Submit Button

type="submit" creates a button used to submit the form.

<input type="submit" value="Submit">

12. <textarea>

The <textarea> element is used for entering multiple lines of text.

<textarea name="message"></textarea>

13. <select>

The <select> element creates a dropdown list.

<select name="course"> ... </select>

14. <option>

The <option> element defines an option inside a <select> dropdown.

<option value="cse">Computer Science</option>

15. <label>

The <label> element provides a description for an input field.

<label for="username">Username</label>

The for attribute of the label should match the id of the input.

16. placeholder

The placeholder attribute displays a temporary hint inside an input field.

<input type="text" placeholder="Enter your name">

17. required

The required attribute makes an input field mandatory. The form cannot be submitted until the required field is completed.

<input type="email" required>

18. name

The name attribute identifies the form field when form data is submitted.

<input type="text" name="username">

19. value

The value attribute specifies the value associated with an input.

<input type="radio" name="gender" value="male">

20. HTML Form Validation

HTML provides built-in validation attributes that help check user input before submitting the form.

  • required → field must be filled
  • type="email" → checks email format
  • min → specifies minimum numeric value
  • max → specifies maximum numeric value
  • minlength → specifies minimum text length
  • maxlength → specifies maximum text length
  • pattern → validates input using a regular expression
<input type="text" name="username" minlength="3" maxlength="20" required >
