Links

<a> Tag is used to create hyperlinks in HTML.

Basic Example: <a href="https://www.google.com"> Google </a>

  • <a> → creates a hyperlink
  • href → specifies the destination URL
  • target → specifies where to open the link
  • rel → defines the relationship between the current page and linked page

1. Absolute URL

An absolute URL contains the complete web address.

<a href="https://www.yt.com">yt </a>

2. Relative URL

A relative URL points to a file within the same website or project.

<a href="about.html">About Us</a>

3. target Attribute

The target attribute specifies where the linked page should open.

<a href="https://www.google.com" target="_blank"> Open Google </a>
  • _blank → opens in a new tab
  • _self → opens in the current tab
  • _parent → opens in the parent frame
  • _top → opens in the full window

4. rel Attribute

The rel attribute defines the relationship between the current page and the linked page.

<a href="https://example.com" target="_blank" rel="noopener noreferrer"> Example </a>
  • noopener → prevents the new page from accessing the opener
  • noreferrer → prevents sending the referrer information

5. Email Link

Use mailto: to create an email link.

<a href="mailto:example@gmail.com"> Send Email </a>

6. Telephone Link

Use tel: to create a telephone link.

<a href="tel:+919876543210"> Call Us </a>

7. Internal Page Link

An internal link connects one page of a website to another page.

<a href="about.html"> About Us </a>

8. Anchor Link

An anchor link moves the user to a specific section of the same page.

<a href="#contact"> Go to Contact </a> <h2 id="contact"> Contact Us </h2>

Images

<img> Tag is used to display images on a web page.

Basic Example: <img src="image.jpg" alt="My Image">

  • <img> → displays an image
  • src → specifies the image path or URL
  • alt → provides alternative text for the image
  • width → specifies the image width
  • height → specifies the image height

1. src Attribute

The src attribute specifies the location of the image.

<img src="image.jpg" alt="My Image">

2. alt Attribute

The alt attribute provides alternative text if the image cannot be displayed.

<img src="image.jpg" alt="Beautiful Mountain">

3. width Attribute

The width attribute specifies the width of the image.

<img src="image.jpg" alt="Mountain" width="500">

4. height Attribute

The height attribute specifies the height of the image.

<img src="image.jpg" alt="Mountain" height="300">

5. Image Paths

Images can be loaded using absolute or relative paths.

Relative path:

<img src="images/photo.jpg" alt="Photo">

Absolute URL:

<img src="https://example.com/photo.jp" alt="Photo">

6. Responsive Images

A responsive image automatically adjusts its size according to the available screen width.

<img src="image.jpg" alt="Responsive Image" style="max-width: 100%; height: auto;" >

7. <figure> Element

The <figure> element is used to group an image with related content such as a caption.

<figure> <img src="mountain.jpg" alt="Mountain"> <figcaption>Beautiful Mountain</figcaption> </figure>

8. <figcaption> Element

The <figcaption> element provides a caption or description for the content inside a <figure>.
