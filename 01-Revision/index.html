Links

<a> Tag is used to create hyperlinks in HTML.

Basic Example: <a href="https://www.google.com"> Google </a>

  • <a> → creates a hyperlink
  • href → specifies the destination URL
  • target → specifies where to open the link
  • rel → defines the relationship between the current page and linked page

1. Absolute URL

An absolute URL contains the complete web address.

<a href="https://www.yt.com">yt </a>

2. Relative URL

A relative URL points to a file within the same website or project.

<a href="about.html">About Us</a>

3. target Attribute

The target attribute specifies where the linked page should open.

<a href="https://www.google.com" target="_blank"> Open Google </a>
  • _blank → opens in a new tab
  • _self → opens in the current tab
  • _parent → opens in the parent frame
  • _top → opens in the full window

4. rel Attribute

The rel attribute defines the relationship between the current page and the linked page.

<a href="https://example.com" target="_blank" rel="noopener noreferrer"> Example </a>
  • noopener → prevents the new page from accessing the opener
  • noreferrer → prevents sending the referrer information

5. Email Link

Use mailto: to create an email link.

<a href="mailto:example@gmail.com"> Send Email </a>

6. Telephone Link

Use tel: to create a telephone link.

<a href="tel:+919876543210"> Call Us </a>

7. Internal Page Link

An internal link connects one page of a website to another page.

<a href="about.html"> About Us </a>

8. Anchor Link

An anchor link moves the user to a specific section of the same page.

<a href="#contact"> Go to Contact </a> <h2 id="contact"> Contact Us </h2>

Images

<img> Tag is used to display images on a web page.

Basic Example: <img src="image.jpg" alt="My Image">

  • <img> → displays an image
  • src → specifies the image path or URL
  • alt → provides alternative text for the image
  • width → specifies the image width
  • height → specifies the image height

1. src Attribute

The src attribute specifies the location of the image.

<img src="image.jpg" alt="My Image">

2. alt Attribute

The alt attribute provides alternative text if the image cannot be displayed.

<img src="image.jpg" alt="Beautiful Mountain">

3. width Attribute

The width attribute specifies the width of the image.

<img src="image.jpg" alt="Mountain" width="500">

4. height Attribute

The height attribute specifies the height of the image.

<img src="image.jpg" alt="Mountain" height="300">

5. Image Paths

Images can be loaded using absolute or relative paths.

Relative path:

<img src="images/photo.jpg" alt="Photo">

Absolute URL:

<img src="https://example.com/photo.jp" alt="Photo">

6. Responsive Images

A responsive image automatically adjusts its size according to the available screen width.

<img src="image.jpg" alt="Responsive Image" style="max-width: 100%; height: auto;" >

7. <figure> Element

The <figure> element is used to group an image with related content such as a caption.

<figure> <img src="mountain.jpg" alt="Mountain"> <figcaption>Beautiful Mountain</figcaption> </figure>

8. <figcaption> Element

The <figcaption> element provides a caption or description for the content inside a <figure>.

Tables

HTML tables are used to organize and display data in rows and columns.

1. <table>

The <table> element is used to create an HTML table.

2. <tr>

The <tr> element defines a table row.

3. <th>

The <th> element defines a table header cell. By default, header text is bold and centered.

4. <td>

The <td> element defines a normal table data cell.

5. <thead>

The <thead> element groups the header rows of a table.

6. <tbody>

The <tbody> element groups the main data rows.

7. <tfoot>

The <tfoot> element groups the footer rows of a table.

8. rowspan

The rowspan attribute allows a cell to span multiple rows.

<td rowspan="2">Total</td>

9. colspan

The colspan attribute allows a cell to span multiple columns.

<th colspan="3">Student Details</th>

Forms

HTML forms are used to collect information from users and send that information to a server.

1. <form>

The <form> element is used to create an HTML form.

<form> ... </form>

2. <input>

The <input> element is used to create different types of input fields.

<input type="text">

3. Text Input

type="text" creates a field for entering normal text.

<input type="text" name="username">

4. Email Input

type="email" is used to collect an email address. The browser can check whether the entered value has a valid email format.

<input type="email" name="email">

5. Password Input

type="password" hides the characters entered by the user.

<input type="password" name="password">

6. Number Input

type="number" is used to enter numeric values.

<input type="number" name="age">

7. Date Input

type="date" allows the user to select a date.

<input type="date" name="dob">

8. Radio Button

type="radio" allows the user to select one option from a group of related options.

<input type="radio" name="gender" value="male"> Male

Radio buttons that belong to the same group should have the same name.

9. Checkbox

type="checkbox" allows the user to select one or more options.

<input type="checkbox" name="skills" value="html"> HTML

10. File Input

type="file" allows the user to select a file from their device.

<input type="file" name="resume">

11. Submit Button

type="submit" creates a button used to submit the form.

<input type="submit" value="Submit">

12. <textarea>

The <textarea> element is used for entering multiple lines of text.

<textarea name="message"></textarea>

13. <select>

The <select> element creates a dropdown list.

<select name="course"> ... </select>

14. <option>

The <option> element defines an option inside a <select> dropdown.

<option value="cse">Computer Science</option>

15. <label>

The <label> element provides a description for an input field.

<label for="username">Username</label>

The for attribute of the label should match the id of the input.

16. placeholder

The placeholder attribute displays a temporary hint inside an input field.

<input type="text" placeholder="Enter your name">

17. required

The required attribute makes an input field mandatory. The form cannot be submitted until the required field is completed.

<input type="email" required>

18. name

The name attribute identifies the form field when form data is submitted.

<input type="text" name="username">

19. value

The value attribute specifies the value associated with an input.

<input type="radio" name="gender" value="male">

20. HTML Form Validation

HTML provides built-in validation attributes that help check user input before submitting the form.

  • required → field must be filled
  • type="email" → checks email format
  • min → specifies minimum numeric value
  • max → specifies maximum numeric value
  • minlength → specifies minimum text length
  • maxlength → specifies maximum text length
  • pattern → validates input using a regular expression
<input type="text" name="username" minlength="3" maxlength="20" required >

Semantic HTML

Semantic HTML means using HTML elements that clearly describe the meaning and purpose of their content.

Semantic elements make websites easier to understand for developers, browsers, search engines, and screen readers.

1. What is Semantic HTML?

Semantic HTML uses meaningful HTML elements instead of generic elements such as <div>.

<header>Website Header</header>

The <header> element clearly tells us that the content represents a header.

2. <header>

The <header> element represents introductory content or a header for a page or section.

<header> <h1>My Website</h1> </header>

3. <nav>

The <nav> element contains navigation links.

<nav> <a href="home.html">Home</a> </nav>

4. <main>

The <main> element contains the main content of the webpage.

A page should normally have only one main content area.

<main> Main Website Content </main>

5. <section>

The <section> element represents a thematic section of content.

<section> <h2>Services</h2> </section>

6. <article>

The <article> element represents independent, self-contained content.

Examples include:

  • Blog posts
  • News articles
  • Forum posts
  • Product reviews
<article> <h2>HTML Tutorial</h2> <p>Learn HTML...</p> </article>

7. <aside>

The <aside> element contains content that is related to the main content but not part of its primary flow.

Examples:

  • Sidebars
  • Related articles
  • Advertisements
  • Additional information
<aside> Related Articles </aside>

8. <footer>

The <footer> element represents footer information for a page or section.

<footer> <p>Copyright 2026</p> </footer>

9. <figure>

The <figure> element represents self-contained content such as an image, diagram, chart, or illustration.

<figure> <img src="image.jpg" alt="Mountain"> <figcaption>Mountain Landscape</figcaption> </figure>

10. <time>

The <time> element represents a specific date, time, or duration.

<time datetime="2026-08-15"> August 15, 2026 </time>

11. Semantic vs Non-Semantic HTML

Semantic elements clearly describe their purpose.

  • <header> → Header content
  • <nav> → Navigation
  • <main> → Main content
  • <article> → Independent content
  • <footer> → Footer content

Non-semantic elements do not describe their purpose.

  • <div>
  • <span>

Benefits of Semantic HTML

  • Improves code readability
  • Improves accessibility
  • Helps search engines understand the page
  • Makes website structure easier to maintain
  • Provides meaningful document structure

Accessibility

Web accessibility means designing websites so that people with different abilities can use, understand, and navigate them.

Accessible websites are easier to use with screen readers, keyboards, and other assistive technologies.

1. alt Attributes

The alt attribute provides alternative text for an image. Screen readers can read this text to users who cannot see the image.

<img src="profile.jpg" alt="Profile photograph">

Always provide meaningful alt text when an image contains useful information.

For decorative images, an empty alt attribute can be used:

<img src="decoration.png" alt="">

2. Proper Heading Hierarchy

Headings should follow a logical hierarchy using <h1> through <h6>.

<h1>Website Title</h1> <h2>About Us</h2> <h3>Our Team</h3>

Avoid choosing headings only because of their visual size. Headings should describe the structure of the content.

3. Labels for Forms

Every form input should have a meaningful <label>.

<label for="email">Email</label> <input type="email" id="email" name="email">

The label's for attribute should match the input's id.

4. Keyboard Accessibility

A website should be usable without a mouse. Users should be able to navigate interactive elements using the keyboard.

Common keyboard keys include:

  • Tab → move to the next interactive element
  • Shift + Tab → move to the previous element
  • Enter → activate links and buttons
  • Space → activate buttons and controls

5. ARIA Basics

ARIA stands for Accessible Rich Internet Applications.

ARIA attributes provide additional information to assistive technologies when normal HTML semantics are not sufficient.

<button aria-label="Close menu"> X </button>

Common ARIA attributes include:

  • aria-label → provides an accessible name
  • aria-labelledby → references another element for a name
  • aria-describedby → references descriptive information
  • aria-hidden → hides content from assistive technology
  • aria-expanded → indicates whether a control is expanded

6. Accessible Buttons

Use the native <button> element for actions.

<button type="button">Submit</button>

Buttons are keyboard accessible by default and provide semantic meaning to browsers and assistive technologies.

7. Accessible Links

Use the <a> element when the user is navigating to another page or location.

<a href="about.html">About Us</a>

Link text should clearly describe where the link goes.

Good:

<a href="resume.pdf">Download my resume</a>

Avoid:

<a href="resume.pdf">Click here</a>

8. Semantic HTML and Accessibility

Semantic HTML automatically provides useful information to assistive technologies.

  • <nav> → navigation
  • <main> → main content
  • <button> → interactive action
  • <form> → form area
  • <header> → introductory content
  • <footer> → footer content

Accessibility Best Practices

  • Use meaningful alt text
  • Use headings in logical order
  • Use labels with form controls
  • Make interactive elements keyboard accessible
  • Use semantic HTML
  • Use ARIA only when necessary
  • Use clear link and button text
  • Maintain sufficient color contrast

Multimedia

HTML provides several elements for adding multimedia content such as audio, video, and external content to a webpage.

1. <audio>

The <audio> element is used to embed audio content in an HTML page.

<audio controls> <source src="song.mp3" type="audio/mpeg"> </audio>

2. <video>

The <video> element is used to embed video content in a webpage.

<video controls width="500"> <source src="video.mp4" type="video/mp4"> </video>

3. <source>

The <source> element specifies the media file and its MIME type.

It allows you to provide multiple formats so the browser can choose a format it supports.

<video controls> <source src="video.mp4" type="video/mp4"> <source src="video.webm" type="video/webm"> </video>

4. controls

The controls attribute displays the browser's built-in media controls.

For example:

  • Play / Pause
  • Volume
  • Progress bar
  • Fullscreen for video
<video controls> ... </video>

5. autoplay

The autoplay attribute tells the browser to start playing the media automatically when possible.

<video autoplay> ... </video>

Browsers commonly restrict autoplay when the media has sound. Combining autoplay with muted is commonly used for automatically playing videos.

6. muted

The muted attribute starts audio or video without sound.

<video autoplay muted> ... </video>

7. loop

The loop attribute makes the media automatically start again after it finishes.

<audio controls loop> <source src="music.mp3" type="audio/mpeg"> </audio>

8. <iframe>

The <iframe> element embeds another webpage or external content inside the current webpage.

<iframe src="https://example.com" width="600" height="400"> </iframe>

9. Embedding YouTube Videos

YouTube videos can be embedded using an <iframe>.

You can get the embed code from YouTube using:

  1. Open a YouTube video.
  2. Click Share.
  3. Select Embed.
  4. Copy the generated iframe code.
<iframe src="https://www.youtube.com/embed/VIDEO_ID" title="YouTube video" allowfullscreen> </iframe>

Multimedia Attributes Summary

  • controls → displays media controls
  • autoplay → starts media automatically when allowed
  • muted → starts media without sound
  • loop → repeats the media
  • src → specifies the media source
  • type → specifies the media MIME type

Advanced HTML

Advanced HTML elements provide additional functionality for creating interactive, visual, and responsive webpages.

1. <details>

The <details> element creates a disclosure widget that the user can open and close.

<details> ... </details>

2. <summary>

The <summary> element provides the visible heading that the user clicks to open or close the <details> element.

<details> <summary>What is HTML?</summary> <p>HTML creates webpage structure.</p> </details>

3. <dialog>

The <dialog> element represents a dialog box or modal window.

<dialog> Hello! </dialog>

JavaScript methods such as showModal() and close() can be used to control a dialog.

4. <progress>

The <progress> element represents the completion progress of a task.

<progress value="70" max="100"> </progress>

In this example, the progress is 70%.

5. <meter>

The <meter> element represents a scalar measurement within a known range.

Examples include:

  • Disk usage
  • Battery level
  • Score
  • Temperature
<meter min="0" max="100" value="75"> 75% </meter>

6. <canvas>

The <canvas> element provides a drawing area that JavaScript can use to draw graphics.

<canvas id="myCanvas" width="300" height="150"> </canvas>

Canvas can be used for:

  • Charts
  • Games
  • Animations
  • Graphics

7. <svg>

SVG stands for Scalable Vector Graphics. It is used to create vector-based graphics directly in HTML.

<svg width="100" height="100"> <circle cx="50" cy="50" r="40" /> </svg>

SVG graphics can scale without losing quality.

8. <picture>

The <picture> element allows different images to be provided for different screen sizes or formats.

<picture> <source media="(max-width: 600px)" srcset="mobile.jpg"> <img src="desktop.jpg" alt="Example"> </picture>

9. <source>

The <source> element specifies alternative media resources.

It can be used inside elements such as <picture>, <audio>, and <video>.

<picture> <source srcset="image.webp" type="image/webp"> <img src="image.jpg" alt="Image"> </picture>

10. data-* Attributes

data-* attributes allow developers to store custom data on HTML elements.

<button data-product-id="101" data-category="laptop"> Buy </button>

JavaScript can access this information using the dataset property.

element.dataset.productId

Advanced HTML Summary

  • <details> → expandable content
  • <summary> → heading for details
  • <dialog> → dialog/modal
  • <progress> → task progress
  • <meter> → measurement within a range
  • <canvas> → JavaScript drawing area
  • <svg> → vector graphics
  • <picture> → responsive image sources
  • <source> → alternative media source
  • data-* → custom element data

HTML for Development

HTML for development focuses on creating webpages that are well-structured, responsive, accessible, SEO-friendly, and easy to maintain.

1. <meta charset="UTF-8">

The charset meta tag specifies the character encoding used by the webpage.

UTF-8 supports a large number of characters, symbols, and languages.

<meta charset="UTF-8">

2. Viewport Meta Tag

The viewport meta tag makes a webpage responsive on mobile devices.

<meta name="viewport" content="width=device-width, initial-scale=1.0" >
  • width=device-width → uses the device's screen width
  • initial-scale=1.0 → sets the initial zoom level

3. <meta name="description">

The description meta tag provides a short description of the webpage. Search engines may use this description in search results.

<meta name="description" content="Learn HTML, CSS and JavaScript development." >

4. <meta name="author">

The author meta tag specifies the author or creator of the webpage.

<meta name="author" content="Tabish Firoz" >

5. Favicon

A favicon is the small icon displayed in the browser tab next to the webpage title.

<link rel="icon" type="image/png" href="favicon.png" >

6. Open Graph Basics

Open Graph meta tags control how a webpage appears when its URL is shared on social media platforms.

<meta property="og:title" content="HTML Development Course"> <meta property="og:description" content="Learn complete HTML development." > <meta property="og:image" content="preview.png" > <meta property="og:url" content="https://example.com" >

Common Open Graph properties include:

  • og:title
  • og:description
  • og:image
  • og:url
  • og:type

7. SEO-Friendly HTML

SEO-friendly HTML helps search engines understand the content and structure of a webpage.

  • Use meaningful page titles
  • Use proper heading hierarchy
  • Use semantic HTML
  • Use descriptive links
  • Add meaningful image alt text
  • Use a useful meta description
  • Avoid unnecessary HTML elements
<h1>Complete HTML Development Course</h1>

8. Accessibility Basics

Accessibility means making webpages usable by people with different abilities and assistive technologies.

  • Use alt for meaningful images
  • Use labels for form inputs
  • Use semantic HTML
  • Maintain proper heading hierarchy
  • Make interactive elements keyboard accessible
  • Use ARIA when necessary
<label for="email">Email</label> <input id="email" type="email">

9. HTML Validation

HTML validation checks whether your HTML follows the HTML standard and helps detect structural errors.

Validation can help identify:

  • Missing closing tags
  • Invalid attributes
  • Incorrect nesting
  • Duplicate IDs
  • Invalid HTML structure
<img src="image.jpg" alt="Mountain">

A good development workflow is:

Write HTML → Validate → Fix errors → Test → Deploy

10. Clean HTML Structure

Clean HTML means writing organized, readable, semantic, and maintainable markup.

  • Use proper indentation
  • Use semantic elements
  • Use meaningful class names
  • Avoid unnecessary nested elements
  • Keep HTML readable
  • Use comments where useful
  • Avoid duplicate IDs
<header> <nav>...</nav> </header> <main> <section> ... </section> </main> <footer> ... </footer>
