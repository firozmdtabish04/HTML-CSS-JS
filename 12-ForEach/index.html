forEach is a programming concept and method for iterating (looping) through each item in a collection (like an array or
        list), executing a specific function or code block once for every element, making it easier and cleaner to process
        collections without managing manual counters. 
        It's available in many languages (JavaScript, Java, C#, PHP) and provides
        a concise way to perform actions like printing, modifying, or calculating for each item, though limitations like
        inability to break early exist in some implementations.
           
    

        JavaScript: 
        const fruits = ["apple", "banana"];
        fruits.forEach(function(fruit) {
        console.log(fruit); // Logs "apple", then "banana"
        });
    
        java:
        String[] cars = {"Volvo", "BMW"};
        for (String car : cars) {
        System.out.println(car); // Prints "Volvo", then "BMW"
        }
